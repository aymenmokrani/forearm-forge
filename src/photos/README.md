# Exercise photos

From [free-exercise-db](https://github.com/yuhonas/free-exercise-db) by yuhonas,
released into the public domain (Unlicense). Resized to 480 px wide; the app tints
them to its palette at display time.

Only exercises whose photo shows the same movement get one (see `src/domain/guide.ts`);
the rest show steps and tips only.
